# Spec 00: Overview & Architecture

## 1. Goal
Rebuild the frontend of **SafeSphere AI**, a web application helping public figures, creators, and Page admins identify abusive comments on their Facebook Page posts, spot repeat offender accounts across posts, and review safety findings with human-in-the-loop verification.

## 2. Audience & Scope
- **Target Users:** Public figures, creators, digital media teams, and community moderators facing online abuse in Bangladesh and globally (supporting Bangla, Banglish, English).
- **Scope:** Demo build. Real Meta connection and post fetching; simulated scans, findings, analytics, cases, and reporting generated by the backend and local deterministic seed data.

## 3. Technology Stack
- **Framework:** Next.js 16 (App Router) + React 19 + TypeScript (Strict)
- **Styling:** Tailwind CSS v4, shadcn/ui (Accessible Teal theme, 0.5rem radius)
- **Typography:** Geist Sans, Geist Mono, Noto Sans Bengali (1.6 line height on Bangla)
- **Icons:** lucide-react
- **Data Fetching & State:** TanStack Query (`@tanstack/react-query`)
- **Forms & Validation:** react-hook-form, @hookform/resolvers, zod
- **Animations:** `motion` (`motion/react`), Lenis smooth scrolling
- **Theme:** `next-themes` (Light default, dark toggle, no transition flash)
- **Notifications:** `sonner` toasts
- **Charts:** shadcn chart / Recharts
- **API Typing:** `openapi-typescript` against FastAPI backend `/openapi.json`
- **Proxy:** Same-origin rewrite `/api/*` -> FastAPI port 8000. `credentials: "include"`, httpOnly session cookie.

## 5. Build Order
1. Specs creation (`docs/specs/*.md`) & Open questions analysis
2. Dependencies, Accessible Teal theme, fonts, providers, client, types
3. Public Landing Page (`/`) with sticky blurred header and scroll storytelling
4. Authentication (`/login`, `/register`, middleware)
5. App Shell & Layout (`Sidebar`, TopBar, UserMenu, Demo badge)
6. Dashboard & Facebook Connection (`/dashboard`)

11. Future Mock Screens (`/cases`, `/reports`, `/settings`)
12. Seed fallback integration & QA acceptance verification
