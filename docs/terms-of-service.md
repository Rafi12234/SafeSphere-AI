Connecting a Facebook Page requires authorization through Meta's official Facebook login process.

SafeSphere AI is an independent project and is not endorsed by Meta. Facebook access is subject to Meta's policies, permissions, and technical availability.

Personal Facebook timelines are not supported as connected Pages.

The current harassment-scanning feature uses scripted fictional comments and predefined classifications. No real Facebook comments are analyzed, and no live artificial-intelligence model is executed.

These demonstration results must not be used as evidence against real individuals, as the basis for accusations, or for automated moderation decisions.
